O diretorio canonico de ADRs existentes e `docs/adr/` em minusculo.

Este diretorio existe para compatibilidade com referencias que usam `docs/ADR/`.
Nao duplique decisoes aqui. Ao criar nova decisao:

1. Criar arquivo numerado em `docs/adr/`.
2. Atualizar indice ou referencias neste README se necessario.
3. Registrar impacto em `docs/PROJECT_MEMORY.md` e `docs/SESSION_MEMORY.md`.
